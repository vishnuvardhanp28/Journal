# Journal research workspace

This repository contains the journal papers and working material for P. Vishnu Vardhan's image-encryption reproducibility audit.

## Contents

- The six supplied research-paper PDFs and the IEEE journal-list spreadsheet are in the repository root.
- `research/` contains the manuscript and figures, BibTeX references, research code, datasets and source archives, analysis outputs, image-encryption demonstrations, and submission/delivery ZIP files.
- The `research/work/` directory contains working files and the local Python dependency bundle used for the experiments.

## Manuscript

The current Overleaf-ready IEEE project is `research/deliverables/Overleaf_TIFS_Research_Draft.zip`. The separate manuscript-only package and code/results supplement are alongside it.

## Reproducibility and reuse

The research README files describe the experiment setup and dataset provenance. Some USC-SIPI image copyrights are unknown; verify image reuse rights before redistributing or submitting those images.
